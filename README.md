# 🎓 PointList - Plataforma Académica Integral

Bienvenido al repositorio oficial de **PointList**, una plataforma académica integral diseñada para optimizar la experiencia de estudio, la gestión de tareas y la comunicación institucional entre docentes y estudiantes.

---

## 📂 Estructura del Repositorio y Versiones

Este repositorio está organizado en dos módulos principales según la plataforma de destino:

### 💻 1. `PointListv14_For_PC/` (Versión de Escritorio y Web)
Esta carpeta contiene la versión de escritorio **PointList v14.2 completa** desarrollada en Python con el framework Flet. Funciona como aplicación nativa de escritorio (Windows/Mac/Linux) y soporta servidor Web local en paralelo.

**Características principales:**
* 📝 **Asignaciones y Tareas (Estilo Google Classroom):** Módulo interactivo para que los profesores creen, asignen y califiquen tareas con notas y retroalimentación, y los estudiantes puedan responder y adjuntar archivos (PDF, DOCX, ZIP, imágenes).
* 💬 **Mensajería Instantánea:** Sistema de chat entre estudiantes y profesores con menú contextual al hacer clic derecho, creación de grupos y gestión de chats archivados.
* 📊 **Notas y Calificaciones:** Gestión de calificaciones por asignatura y asignación de notas a estudiantes por parte de los profesores.
* 📅 **Calendario Académico:** Filtro y visualización de eventos académicos de las dos semanas actuales.
* 🤖 **Asistente IA (ChatBot):** Integración con inteligencia artificial (Groq Cloud y Google Gemini) para asistencia en el estudio y análisis de imágenes.
* 🌐 **Modo Híbrido Dual:** Ejecución simultánea en ventana nativa de escritorio y servidor Web navegable (`http://localhost:8550`).

---

### 📱 2. `PointList_for_Android/` (Versión Móvil)
Módulo destinado al desarrollo de la aplicación móvil optimizada para dispositivos **Android**.
* *Estado:* En fase de desarrollo y adaptación para entornos móviles nativos.
