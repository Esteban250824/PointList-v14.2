## Para el "About" - Versión expandida:

### PointList v13
Una plataforma educativa integral para estudiantes diseñada para optimizar su gestión académica, técnicas de estudio y comunicación colaborativa.

**Características destacadas:**
- 📱 Interfaz moderna y responsiva con modo oscuro optimizado
- 📊 Dashboard de notas con gráficas interactivas y estadísticas
- ⏱️ Técnicas de estudio Pomodoro con temporizador integrado
- 💬 Mensajería colaborativa con soporte multimedia
- 🤖 ChatBot IA (PointBit) integrado con OpenAI
- 🌍 Soporte multiidioma (Español, Inglés, Portugués)
- 🔐 Autenticación segura con encriptación de contraseñas
- 📱 Multiplataforma: Web, Android, iOS

**Stack:** Python • Flet • PostgreSQL • OpenAI API
