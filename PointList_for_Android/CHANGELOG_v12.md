# Changelog PointList v12 - "DLC & Optimización Final"

## 🚀 Mejoras Visuales y UX
- **Gráficas Ensanchadas**: Se aumentó el ancho de las barras en las gráficas de notas para una mejor visualización de los datos.
- **Modo Oscuro Optimizado**: Los campos de texto en el perfil ahora cambian de color instantáneamente al activar el modo oscuro, eliminando los fondos blancos molestos.
- **Identificación de Profesores**: Los estudiantes ahora pueden ver quién les envió cada nota directamente en la tarjeta de calificación.
- **Enlace de Recuperación**: Corregido el enlace de "¿Olvidaste tu contraseña?" que ahora redirige correctamente a la página de recuperación en lugar de saltar al inicio.

## 🤖 Evolución de PointBit
- **Rebranding**: PointBit ha dejado de ser una "mascota" para convertirse en un **Asistente Académico Inteligente**. Se eliminaron las referencias a mascotas y se actualizó su personalidad.
- **Borrado Instantáneo (Retraso Nulo)**: El historial de conversaciones ahora se elimina inmediatamente de la interfaz de usuario sin necesidad de clics dobles ni esperas.
- **Interfaz Limpia**: Se eliminaron iconos y textos innecesarios para una experiencia de chat más enfocada.

## 🛠️ Correcciones Técnicas
- **Persistencia de Configuración**: Se añadieron protecciones para evitar fallos cuando el servicio de base de datos no responde al cambiar el tema.
- **F-Strings Seguras**: Se corrigieron errores de sintaxis en el renderizado de notas para asegurar la compatibilidad con todas las versiones de Python.
- **Mapeo de Vistas**: Se integró formalmente la página de recuperación en el controlador de navegación.
